Web Development Glossary

HTML
A markup language used to create the structure and content of webpages.
CSS
A style sheet language used to control the appearance and layout of wepages.
Browser
A software application used to control the appearance and layout of webpages.
Server
A software application used to access and display webpages, such as Chrome or Firefox.
Domain
The readable web address used to access a website, such as example.com
